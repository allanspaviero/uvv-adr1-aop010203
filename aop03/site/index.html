Sobre este projeto

Projeto de Extensão da disciplina Arquitetura de Dados Relacionais I, da Universidade Vila Velha. O objetivo é armazenar os preços de combustíveis da região em um banco de dados relacional e devolver essa informação à comunidade de forma consultável.

As tabelas desta página não são um resumo pré-calculado. O navegador abre o banco de dados e executa os mesmos arquivos .sql do projeto físico, entregue na etapa anterior. É por isso que cada consulta consegue mostrar o comando que a produziu.
